# PDP Image Prompts — Nano Banana Pro 2

For `theme/sections/evenroom-pdp-sa1.liquid`. **Product:** a white (or bronze) register cover with two fans behind a louvred grille, a small black touch display panel on the right-hand end, and a separate slim remote.

**House rules:** real prop branding stays — never write "unbranded" or "no logos." Deliberate imperfection so nothing reads as generated. Degrees in the diagram are mono. Accent `#B4553A`, base `#FAF7F2`.

- Generate **1a, 1c, 1d and 2** first. The rest are nice-to-have.
