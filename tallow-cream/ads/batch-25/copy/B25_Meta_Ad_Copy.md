# B25 Meta Ad Copy: Primary Text, Headline, Description (2 each, 3 ads)

**Date:** 2026-07-07
**Structure:** 2 primary text / 2 headline / 2 description per ad, matching the account's 3:2:2 Marksman convention. Primary text stays short and native (this is a Pubity-format image ad, the image itself already carries the hook/claim, primary text's only job is to nudge the click toward the listicle, not repeat the image). Headline restates the core claim in a few words for the feed's bold line. Description carries the offer stack (price, guarantee, ingredient count), consistent with the account's existing B22 Meta copy convention.
**Destination:** each ad links to its matching personalized listicle (Confrontation → `tallow-listicle-confrontation`, 43-vs-4 → `tallow-listicle-labelcount`, Legibility → `tallow-listicle-readaloud`).

## Notes
- Descriptions are identical across all 3 ads by design, they're offer-stack facts (price, ingredient count, guarantee), not angle-specific, matching how B22's Meta Description field was used ("$49.99. Free shipping. 60-day refund.").
- Primary text deliberately does NOT restate the image's headline claim, its only job is a short nudge toward the click, the image and the listicle are doing the actual selling.
- No banned phrases, no medical claims, no fabricated stats, consistent with `Tallow_Ad_Creative_Principles.md`.
