**Test variable:** Image only. Where B23C1 pushed one lever (a face, still shot candid/camouflage), this cell pushes further: a bright, warm, genuinely produced-feeling lifestyle photo, closer to the swipe file's most polished examples (Ad #2's joyful lake embrace, Ad #5's bright park selfie), explicitly accepting more camouflage loss in exchange for maximum scroll-stop and the lowest possible CPM. Uses the Day 21 beat already in the copy: "Elaine hugged me at book club and smiled and didn't say anything." This is the one moment in the ad that is structurally a warm, mutual, camera-ready embrace, the same shape as Ad #2's lake photo, so the boldness isn't arbitrary, it's the single beat in this specific story that supports it.

## What this deliberately gives up

This image no longer reads as an "accidental grainy iPhone snapshot," the core camouflage premise the rest of the account is built on. It reads as a nice photo of two friends, still plausible as something a real person might post, but noticeably more composed and well-lit than the candid standard. This is the intended risk, per founder direction: test how much CPM improves when camouflage is loosened toward the swipe file's own visual register, using the same underlying proven copy as the control.

## Compliance check

No new claims, no product visible, no health/medical language, zero em dashes. This is a visual-format test only.

## Why this cell

Isolates "how much camouflage-breaking helps CPM" as its own variable, distinct from B23C1's more conservative face-inclusion test. Running both alongside the original faceless baseline gives three points on the same curve (faceless -> candid face -> produced/bold face) instead of a single before/after.
