# B22C1 - News-Chyron: The Mechanism

**Batch:** 22 (format test, new isolated campaign replacing whiteboard's budget)
**Cell:** C1 of 3
**Format:** News-chyron / breaking-news graphic (format held constant across all 3 cells, this is the controlled variable)
**Ported element:** The mechanism (water evaporates, fat absorbs). Cross-validated from `Converter_Pattern_Synthesis_v2.md`: the ONLY element already proven to survive translation into a cheap format twice (inside B9C3's narrative via Winnie's dialogue, and stripped bare as B19C2's whiteboard diagram, which ran $11-77 CPM).
**Why this format:** Founder-flagged reference set showed the breaking-news chyron aesthetic getting low CPM across two unrelated categories (dog joint supplement, cropped sweatpants), independent evidence it's a genuinely bold, scroll-stopping visual style, not a one-off.

**Format correction (2026-07-02):** first version of this prompt was built as a screenshot-of-a-TV-broadcast, wrong read on the reference images. The actual reference ads (dog supplement, sweatpants) are sharp, well-lit, in-focus produced product/lifestyle photos with a bold badge tag, bold headline overlay, and an inset circle callout showing a proof graphic, not a grainy candid TV screenshot. Rewritten to match. This format is openly produced/branded, a deliberate departure from native's camouflage requirement, which is fine since B22 was never meant to read as camouflage-native in the first place.

**Compliance note:** The ad borrows the AESTHETIC of a news graphic only. Nothing in the copy claims this was actually broadcast, reported, or endorsed by any outlet. No real network names, call letters, or logos anywhere in the image, fictional/generic only, to avoid trademark exposure and any implied-endorsement claim.
