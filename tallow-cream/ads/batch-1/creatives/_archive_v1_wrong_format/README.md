# Archive — Batch 1 Creatives v1 (Wrong Format)

> **Why these are here:** These were the first attempt at Batch 1 creatives. They were generated using the wrong prompt format — beauty photography style, lifestyle shots, polished editorial images. None of them follow the camouflage ad format from `origins-training/swipe-file/origins-native-swipe`.
>
> **What was wrong:**
> - Beauty photography aesthetic (looked like Facebook ads)
> - Lifestyle scenes with women, bathrooms, couples
> - Did NOT show the pain point or ideal outcome
> - Did NOT match any of the proven Origins camouflage examples
>
> **The correct format:** See `B1_Creative_Prompts.md` for the rewritten prompts. Camouflage ad images should be either:
> - Extreme macro close-ups of skin (pain point: normal everyday dryness, OR outcome: hydrated glowing skin)
> - Documentary-style "found" reference images
>
> NOT polished beauty photos. NOT product shots. NOT lifestyle.
>
