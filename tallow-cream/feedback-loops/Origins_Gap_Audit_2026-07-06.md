# Origins Training Gap Audit: What the Folder Teaches That We Haven't Been Doing

**Date:** 2026-07-06
**Source:** full pass through `origins-training/` (all origins-notes docx files, brief template, ad formats, offers module, feedback-loop template, cheat sheet, testing methods). Companion to `Brand_Mastery.md`, which fixed the avatar/sophistication/awareness gaps. This doc covers everything else found.

## Ranked gaps, biggest impact first

### GAP 1: The 3:2:2 testing structure has never been used
Origins' core testing unit inside Meta: **3 creatives, 2 body copies, 2 headlines per concept**, letting Meta's delivery pick winning combinations. Every batch this account has ever run is 1 creative : 1 copy : 1 headline per cell. That means each cell tests exactly one combination and learns nothing about whether a different headline or copy would have saved it. B22C1 is the perfect example: the founder's own diagnosis was "the headline is weak," but the test structure had no second headline in it to prove that cheaply. A 3:2:2 on the same concept would have answered it inside the original spend. **Adopt for all future image batches.**

### GAP 2: Marksman vs Sniper methods were never operationalized
Origins' two testing modes: **Marksman** (test the best angle from each of several sub-avatars at once in a 3:2:2, images only, to find DIRECTION fast when data is thin) then **Sniper** (deep iteration on ONE validated angle, best suited to video, once direction exists). The account has been doing unstructured half-marksman batches for 24 batches without naming the phase, and without the discipline of "direction first, depth second." This maps directly onto the current plan: B24 should be run explicitly as a Marksman batch (3 sub-avatars from Brand_Mastery, best angle each, 3:2:2), and the founder's planned video-ads-on-the-winning-angle phase IS the Sniper phase, the training explicitly says video = sniper, images = marksman. The framework already agrees with the plan; now the plan has names and rules.

### GAP 3: The Origins brief template has never been used for a batch
`origins-brief-template` structure: Concept -> Angle(s) (stated twice, deliberately) -> Testing Method (marksman/sniper) -> Format -> per-variation Messaging + Content -> sizes -> TWO copies and TWO headlines. Our cell files evolved their own format that captures most of this (and now sub-avatar/awareness/sophistication per Brand_Mastery Part 8), but they never carry a second copy/headline (Gap 1) and never state the testing method (Gap 2). **Fix: fold "Testing Method" and the 2-copy/2-headline requirement into the standard cell file format.**

### GAP 4: The format library is mostly unexplored, and one warning directly touches B22
Formats we've tried: native image, whiteboard/infographic, badge graphic, product photography. Never tried from the Origins list: **slideshow video with text** (flagged weeks ago in the gap analysis, still the cheapest video entry, assets already exist), subtitles-over-b-roll, voiceover-b-roll, UGC-style image, quote/text-heavy image, collage, meme-style. Two notable notes from the formats doc: (1) **"Professional shot video: not recommended, doesn't convert super well right now"**, which validates the camouflage instinct and warns the future video phase away from polish; (2) **"🚨 DO NOT FAKE PRESS RELEASE ADS (false advertising)"**, directly relevant to the B22/B24 news-badge format. Our compliance notes already avoid real network names and broadcast claims, but this is a named line in the training: the badge aesthetic is fine, implying real press coverage is not. Keep the discipline.

### GAP 5: Offers must be pre-calculated and NAMED
The offers module's two rules we haven't followed: (1) **before launching any offer, use a profit calculator to set the new ROAS/CPA targets** so success is defined in advance (we did this informally in the Profitability Path doc's math, formalize it when the tin offer goes live); (2) **bundles/offers need a NAME and a REASON** ("The Staple 6-Pack," "Rat Protection Bundle"). Our planned offer is currently unnamed ("free purse tin"). Naming it (e.g. "The Refill Ritual" / "The Purse Jar Set", founder's call) makes it an offer instead of a freebie. Also the module's warning worth remembering: offers are addicting and hard to take away, don't build the funnel to depend on one permanently.

### GAP 6: The pre-launch cheat sheet was never adopted as a QC gate
14 questions in `ad-creatives-feedback-loop-cheatsheat` (does the first 1-2 seconds hook the RIGHT user, does it feel native, would they smile, does it educate creatively, have we applied learnings from previous winners, does it separate us from competitors...). We QC images against prompts (the image-QC gate) but never QC the whole ad against a checklist before launch. **Fix: add the cheat-sheet pass to the pre-launch flow alongside the Stage-5 filter from Brand_Mastery.**

### GAP 7: 9:16 has never been produced
The brief template says sizes needed: **ALWAYS 1080x1920 (9:16)** plus the safe zones (1:1, 4:5). Every asset this account has ever produced is 4:5 only. That means Stories/Reels placements either get cropped 4:5 or don't serve, connecting directly to the never-read placement breakdown (still unrun) and the untested cheaper video/Reels inventory. **Fix: generate 9:16 variants of winning creatives; check the placement breakdown first to see what we're currently serving.**

### GAP 8: `swipe-file/1000-winning-ad-templates` has never been opened
An entire folder of winning ad templates sits unexplored. Worth a browse before the next net-new format decision instead of relying only on the 8-ad native swipe.

### Minor notes, no action needed
- The Origins feedback-loop template is exactly what we already use (hypothesis ranked most-to-least confident -> action). No gap.
- "Escalation" (exaggerating the claim in a clear, relatable way) appears in the cheat sheet as an advanced lever; unexplored but low priority until the basics above are running.
- The mindset/copywriting/find-product modules contain nothing actionable for current state.
