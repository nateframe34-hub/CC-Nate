# Partner Page (Sarah Lawson) — Execution Tracker & Content Calendar

> **Purpose:** Track every planned post across Sarah's organic partner page (@sarahlawson.wellness). Each post has a status, planned date, and notes field. Use this to coordinate the 35+ posts across the seeding period and ongoing monthly cadence.
>
> **Reference:** `Partner_Page_Identity_and_Post_Plan.md` for full copy, `Master_Launch_Timeline.md` for sequencing against brand page and ad partner page.
>
> **How to use:** Update the Status column as you go. Fill in Actual Date once posted. Use Notes for platform feedback, engagement observations, or copy tweaks made at posting time.

---

## Status Key

| Status | Meaning |
|--------|---------|
| `[ ]` | Not started — copy not yet finalized or asset not created |
| `[D]` | Drafted — copy finalized, ready for asset creation |
| `[A]` | Asset ready — image/video/carousel created, ready to post |
| `[S]` | Scheduled — loaded into scheduling tool with date/time set |
| `[P]` | Posted — live on the platform |
| `[X]` | Skipped/Cut — removed from plan with reason in Notes |
