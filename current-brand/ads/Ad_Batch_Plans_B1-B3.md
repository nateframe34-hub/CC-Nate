# Ad Batch Plans — Batches 1-3

> **Product:** Baseline NMN 10-in-1 — 500mg NMN + 8 synergistic ingredients. 120 capsules / 60 servings.
> **Framework:** Angle Isolation Testing — 1 Sub-Avatar, 1 Format, 3 Angles per batch.
> **Principle:** Every ad sells the OUTCOME, not the product. NMN is the mechanism. NAD+ decline is the education. The felt experience is the proof.
> **Analysis reference:** `Swipe_File_Deep_Analysis.md` — full breakdown of every winning ad in the Origins swipe file.
>
> **Brand Identity:**
> - Colors: Teal Deep (#0C3B3F), Teal Mid (#165C5A), Teal Light (#1E7A77), Copper (#C07840), Cream (#F5F0E8), Near Black (#1A1A1A)
> - Typography: Cormorant Garamond (serif, headlines), Plus Jakarta Sans (body), JetBrains Mono (data/stats)
> - Voice: Clean, scientific, anti-hype. No "revolutionary," "game-changing," "miracle," or "breakthrough."

## Testing Methodology

### What We're Testing

**Phase 1 — These 3 batches:** Which sub-avatar has the highest purchase intent, and which angle resonates best within each sub-avatar.

**Phase 2 — After winners emerge:** Take the winning sub-avatar + angle and test 3 different formats (Sniper Method).

### How Each Batch Is Built

Each batch = 1 Ad Set, structured to isolate **angle** as the variable:

- **1 Sub-Avatar** — Every creative in the batch speaks to the same person
- **1 Format** — Every creative uses the same visual format (eliminates format as a variable)
- **3 Angles** — Each creative carries a different angle for that sub-avatar (the thing we're testing)

### Body Copy Rules

**All 3 batches are Native/Camouflage:**
- 3 body copies — 1 per creative, paired 1:1 with its creative
- Each body copy is a complete camouflage story entering through its angle
- In Meta: create 3 separate ads within the ad set (do NOT use Advantage+ Creative mix-and-match — the creative/copy pairs must stay together)
- Still fill in headline + description fields (Meta requires them) but keep generic

### Partner Account Setup

**All 3 batches should run through a partner account, NOT the Baseline brand page.**

Why this matters:
- Every winning ad in the Origins swipe file is clearly NOT running from the brand's official page — they look like personal stories shared by individuals
- Meta's partner feature lets you run ads under a non-brand page, which is critical for native ads to feel authentic
- It dramatically increases the native feel and lowers ad fatigue
- The camouflage effect depends on the ad NOT looking like it comes from a brand

**How to set up:**
1. Create a separate Facebook Page that looks like a personal health/wellness page (not branded as Baseline)
2. Add it as a partner page in Meta Business Manager → Business Settings → Pages → Add → "Request access to a Page"
3. Run B1-B3's camouflage ads from that page
4. The page should have some organic posts to look established — health tips, personal anecdotes, etc.

**⚠️ This is NOT the same as Sarah Lawson's partner page.** Sarah's page (see `Partner_Page_Identity_and_Post_Plan.md`) is a separate organic content engine with its own identity, voice, and posting plan. The ad partner page is a simpler, more generic health/wellness page used solely to make paid ads look native. The B1-B3 body copies feature multiple different narrators (male and female, various ages) — they don't need to match any single page identity. Keep these two pages separate.

### Campaign Structure

- **Campaign type:** Advantage+ Shopping Campaign (or CBO manual campaign)
- **Budget optimization:** Campaign Budget Optimization (CBO) — Meta determines which ad set gets the most spend based on conversion likelihood
- **Placements:** Advantage+ Placements — Meta tests all placements automatically
- **Targeting:** Broad. Age + gender + geo only. No interest targeting. Let the creative do the targeting.
- **Launch:** All 3 ad sets live simultaneously for maximum signal

### Ad Naming Convention

`B[batch]C[creative]_[Format]_[ShortDesc]_A[angle#]-[AngleSlug]`

Example: `B1C1_Native_DoctorVisit_A1-SpecificCause`

# META COMPLIANCE NOTES (ALL 3 BATCHES)

**Body copy compliance:**
- All body copy avoids direct health claims ("cures," "treats," "prevents")
- Uses "supports," "may help," and first-person experience language
- "Individual results may vary" included at the end of every body copy
- No specific percentage claims (e.g., "50% decline" softened to "significant decline")
- Structure/function language only: "supports cellular energy production" not "restores energy"
- Benefits framed as subjective experience, not objective outcomes

**Creative compliance:**
- No before/after photos (which Meta flags)
- Creatives are educational/personal, not medical-claim-making
- Since these are native, the creative itself is very hard to flag — it's personal photos and educational diagrams
- No platform UI mimicry (no fake Facebook/Instagram interfaces) — creatives look native through aesthetic, not through copying platform elements

**Landing page compliance:**
- PDP uses "support," "promote," "maintain" instead of "restore," "reverse," "fix"
- Reviews avoid specific medical symptom claims
- FDA disclaimer visible on product page
- See `pdp-copy.md` Meta Ads Compliance Notes section for full details

# LAUNCH SEQUENCE

## Campaign Setup

- **Campaign type:** Advantage+ Shopping Campaign (or CBO manual)
- **Budget optimization:** CBO — set budget at the campaign level, Meta allocates across ad sets
- **Placements:** Advantage+ Placements
- **Recommended campaign budget:** $100-$150 CAD/day total (Meta distributes across 3 ad sets via CBO)
- **Targeting:** Broad. Age + gender + geo only. No interest targeting. Let the creative do the targeting.
- **Launch:** All 3 ad sets live simultaneously

### Budget Math Check

At $150 CAD/day across 3 ad sets = ~$50/ad set/day = ~$17/creative/day. Meta's learning phase requires ~50 conversions per ad set per week.

| Target CPA | Weekly conversions at $50/day | Exits learning phase? |
|------------|------------------------------|----------------------|
| $7 CAD | ~50/week | ✅ Yes — barely |
| $15 CAD | ~23/week | ❌ No — stuck in learning |
| $25 CAD | ~14/week | ❌ No — stuck in learning |
| $40 CAD | ~9/week | ❌ No — stuck in learning |

**If your target CPA is above ~$10 CAD**, the $150/day budget won't exit learning phase across 3 ad sets. Options:
1. **Increase budget to $200-250/day** — gives each ad set ~$70-85/day, improving learning phase odds
2. **Launch 2 batches first** (B1 + B2), run for 2 weeks, then launch B3 — concentrates spend for faster learning
3. **Use "Purchase" optimization but expect longer learning** — accept 14-21 days instead of 7 for learning phase exit
4. **Define "kill" vs. "iterate" thresholds:** If ALL 3 batches have CPA above 2x target after 14 days, the issue is likely the offer/landing page, not the creative. Pause and diagnose before iterating on ads.

## Week 1-2: Monitor (Do NOT Touch)

Per Origins 15-Checkpoint Cheatsheet:
- Day 1-3: Check delivery. Are all ad sets spending? Are all creatives getting impressions? With CBO, some ad sets will get more spend than others — that's the signal, not a problem.
- Day 4-7: Check CTR. Which creatives are getting clicks? Which body copies?
- Day 7-14: Check CPA. Which ad sets are converting? Which angle combinations?

**DO NOT turn off underperforming ads before Day 7.** Meta needs learning phase time. With CBO, Meta is already deprioritizing weak ad sets — let it work.

## Week 2-3: Read the Signals

After 14 days with sufficient data:
1. **Which sub-avatar won?** The ad set with the lowest CPA = the sub-avatar with the highest purchase intent. This is the primary finding.
2. **Which angle won within the winning sub-avatar?** Look at creative-level metrics (spend allocation, CTR, CPA per creative). The creative that got the most spend = the angle Meta's algorithm found converts best.
3. **Kill** any ad set with CPA 3x+ above target
4. **Scale** winning ad set by 20-30% budget increase every 3-4 days

## Week 3-4: Sniper Method

Take the winning sub-avatar + winning angle and create 3 NEW format variations:
- Same sub-avatar
- Same angle/message
- 3 different visual formats (e.g., native camouflage → us vs them → video testimonial)
- This is Phase 2: format testing with the proven winner

**⚠️ Production Timeline:** Creating 3 new format variations requires creative production. Start concept development during Week 1 so assets are ready when winners emerge in Week 2-3. Don't wait for results before beginning production — have 2-3 format concepts roughed out for each potential winning sub-avatar. You can finalize the one that matches the actual winner.

### Generation Tips for All Prompts

- **Run each prompt 3-4 times** — AI generation has variance, pick the best output
- **Text rendering:** Nano Banana Pro handles text better than most models, but handwritten text (B3C3) may still need touchup. Generate the scene and fix any illegible text in post-production
- **Supplement bottle:** If the bottle doesn't match your actual product in B1C2 or B3C1, generate the scene and composite your real bottle photo in post
- **Faces:** If any faces look slightly off, run through an AI upscaler/refiner for the face area
- **All prompts specify smartphone quality intentionally** — this makes the images look MORE real for native ads, not less. Don't upscale to "professional" quality
- **4:5 aspect ratio** is standard for Meta feed ads. 1:1 works for some placements. Specify in the generation settings
