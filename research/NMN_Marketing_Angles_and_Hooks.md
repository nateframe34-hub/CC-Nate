## HOW TO USE THIS DOCUMENT

### Multi-Angle Concept Testing (Recommended First)
Build ONE ad concept that layers multiple angles:

### Single-Angle Testing (Second Phase)
If the multi-angle concept hits, isolate which angle is driving performance:
- Create 3 ads, each using only ONE sub-avatar's angle
- Test against each other in a 3:2:2 structure
- The winner tells you which sub-avatar resonates most with your audience

### Hook Variation Testing (Third Phase)
Once a winning angle is identified:
- Take all 3 hooks from that angle
- Create 3 ad variations — same angle, different hook
- Test to find the hook that stops the scroll most effectively
- Then iterate on format (static, carousel, UGC video, expert explainer)
