# Self-Audit Checklist (Final Quality Gate Before Delivering)

Run this checklist silently on every deliverable before handing it to the user. If any item fails, fix it before delivering. If a failure cannot be fixed without more information, flag it to the user in a short note.

## Body Copy Audit

### The Prime Directive Check
- [ ] Does the narrator feel like a real person? Would the reader believe this was written by a customer, not a copywriter?
- [ ] Is the tone confession, not testimonial?
- [ ] Does the narrator have a stated reason to share (guilt, responsibility, concern), not just enthusiasm?

### Phase 1 (Research) Check
- [ ] Does the copy use verbatim customer language from the research files — not paraphrased marketing speak?
- [ ] Does the copy speak to the real pain (2am thought), not just the surface complaint?
- [ ] Does the awareness level match the hook style? (Problem Aware = pain-led, Solution Aware = failure-led, Product Aware = proof-led)
- [ ] Is the pain dialed correctly — recognizable, not medical-extreme?

### Phase 2 (Story Elements) Check
- [ ] Does the ad open with a specific scene + inciting incident, NOT a summary?
- [ ] Is there an identifiable theme (the 2am question) running underneath — even if unstated?
- [ ] Are the stakes escalating, not static?
- [ ] Is there a low point of resignation that matches where the reader actually is?
- [ ] Does the transformation include: progressive timeline, unexpected discovery, external validation, identity-level payoff?
- [ ] Are there 3–4 secondary characters, each validating something different?

### Phase 3 (Reader Psychology) Check
- [ ] Does sentence length vary deliberately? (Not uniform short paragraphs.)
- [ ] Is there contrast throughout the copy, not just at the end?
- [ ] Does the emotional register alternate 4+ times? (Not two big blocks.)
- [ ] Is there at least one open loop pulling the reader forward?
- [ ] Is there a pattern interrupt roughly every 200–300 words?
- [ ] Is there a trust ladder (observable → common knowledge → new info → claims)?

### Phase 4 (Hooks and Close) Check
- [ ] Does the hook create curiosity/tension that forces the reader to continue?
- [ ] Does the hook avoid mentioning the product?
- [ ] Does the close connect back to the hook (loop closed, fear answered, promise paid off)?
- [ ] Does the close include risk reversal?
- [ ] Does the close include multiple reasons to act (not just one)?
- [ ] Does the close avoid pitchy language and breaking native tone?

### Product Mention Check
- [ ] Does the product appear only AFTER the belief shift lands? (Roughly 50–65% through the copy?)
- [ ] Are failed past solutions listed specifically by name/type before the product is introduced?

### Length Check
- [ ] Is the length driven by the story, not a word target?
- [ ] No padding to hit a length?
- [ ] No truncation that loses important story beats?

### Compliance Check (Mandatory — Health-Adjacent Categories)

**Flagged words scan — these must be zero across the body copy:**
- [ ] Zero instances of "menopause," "perimenopause," "hormonal," "hormones"
- [ ] Zero "your body" + diagnostic claim ("your body stopped," "your body produces," "your body needs")
- [ ] Zero "your skin/cells/energy is [starving / depleted / broken / damaged / dying]"
- [ ] Zero "Are you [tired/exhausted/etc]?" diagnostic questions
- [ ] Zero "sebum" (replace with "skin's natural oil" or similar)
- [ ] Zero symptom descriptions: "crepey," "papery," "flaky," "saggy," "sunken," "cracked," "dull"
- [ ] Zero "cures," "heals," "fixes," "reverses," "treats," "restores"
- [ ] Zero anti-medical framing ("your doctor is wrong," "don't owe your doctor," "the medical system failed")
- [ ] Zero specific body stats with percentages (e.g., "60% less sebum," "50% drop in NAD+")
- [ ] Zero "If you're [age], [age], [age]..." direct conditional targeting in the close

**Structural compliance — these must all be yes:**
- [ ] Low point uses an external witness (daughter, husband, friend noticing) — NOT hiding/avoiding/shame behaviors from the narrator
- [ ] Physical symptom descriptions replaced with functional descriptions (what it DOES, not what it LOOKS LIKE)
- [ ] Mechanism explanation uses first-person discovery ("I learned," "she told me") — not second-person diagnosis ("your body," "your skin")
- [ ] Close uses social proof framing ("a lot of women I know say the same thing") — NOT "if you're X, Y, Z"
- [ ] If age is referenced, it's a specific number ("I was 49") — NOT a hormonal label ("after menopause")
- [ ] If a medical professional appears, they provide education only — they do NOT explicitly endorse or recommend the product

**If any item fails, rewrite the flagged passage using the 6 middle-ground rules in `compliance-and-readability.md`. Do not deliver until every item passes.**

### Readability Check (6th Grade Reading Level)

- [ ] Average sentence length under 15 words (measure the longest 5 sentences — none should exceed 25 words without strong rhythmic reason)
- [ ] Zero words from the strike list: "actually," "basically," "literally," "really," "very," "completely," "totally"
- [ ] Zero jargon: "sebum," "transepidermal," "fatty acid profile," "molecular level," "dimethicone," "composition," "mechanism," "hyaluronic acid" (unless naming a failed product)
- [ ] Active voice throughout (scan for "was [verb]ed by" and "is being" patterns)
- [ ] Concrete nouns where possible ("jar" not "container," "friend" not "acquaintance")
- [ ] One idea per sentence — no stacked clauses with multiple "and"s or semicolons
- [ ] Short paragraphs — 1–3 sentences max in most paragraphs
- [ ] Read the copy out loud mentally. Any stumbles? Simplify those sentences.

## Headline and Description Audit

- [ ] Headline is ~27 characters or less?
- [ ] Description is ~27 characters or less?
- [ ] Headline reinforces the native tone (not salesy)?
- [ ] Headline echoes the story's emotional core, not the product?
- [ ] Description includes practical reassurance (guarantee, shipping, ingredients)?

## Image Prompt Audit

- [ ] Is the image ONE type (Object / Evidence / Isolation), not a mix?
- [ ] Does it pass the Reddit caption test? ("dealing with this shit again")
- [ ] Is the POV first-person (from the subject), not observer (from outside)?
- [ ] Does the prompt AVOID banned words ("beauty photography," "editorial," "studio," "8K," "cinematic")?
- [ ] Does the prompt INCLUDE anchor words ("candid phone photograph," "documentary," "unretouched")?
- [ ] Is the problem dial correct (normal dryness, not medical condition)?
- [ ] Is the aspect ratio specified (default 4:5 / 1080×1350)?
- [ ] Would the target audience actually take this photo themselves?
- [ ] Can the image be understood in 1 second?

## Deliverable Format Audit

- [ ] All four outputs present (body copy + headline + description + image prompt)?
- [ ] Metadata at top (BXCX, sub-avatar, angle, character type, hook format, awareness level)?
- [ ] Image prompt is inside a code block for easy copy/paste?
- [ ] Aspect ratio is specified?

## Final Sanity Check

- [ ] Read the body copy out loud mentally. Any stumbles or monotony?
- [ ] Would you trust the narrator if you were the reader?
- [ ] Is there ANY moment where the copy shifts into "I'm writing an ad" voice?
- [ ] Would Meta's 2026 multimodal scanner pass this copy without raising CPMs? (If you hesitated on this one, re-run the Compliance Check section.)
- [ ] Could a 12-year-old read this without stumbling?

If everything passes, deliver. If anything fails and you can fix it, fix it and deliver. If anything fails and you can't fix it without more information, deliver what you have with a short note at the bottom flagging the gap.

**Priority order if multiple checks fail:** Compliance Check fails take priority over everything else (a flagged ad doesn't run). Fix those first, then work back through the audit.
