# Meta Ad Compliance Pre-Flight Checklist

> **Purpose:** A per-batch yes/no checklist to run through before submitting any creatives to Meta. Every ad batch gets its own copy of this checklist. Print it, fill it out, keep a record.
>
> **When to use:** Before uploading ANY new ad creative, body copy, or landing page change to Meta Ads Manager. This includes initial launch (B1-B3), champion ad set variations, UGC video ads, and any future batches.
>
> **Reference docs:** `Media_Buying_Plan.md` Part 3.5, `Meta_Health_Ad_Restrictions_Guide.md` Part 6, `Launch_Copy_Review.md` compliance flags.

---

## How to Use This Checklist

1. Copy the "Per-Batch Checklist" section below for each batch you're submitting
2. Fill in the batch name, date, and ad IDs
3. Run through every line item — mark PASS or FAIL
4. If ANY item is FAIL, fix it before uploading. Do not submit and hope for the best.
5. Keep completed checklists in this file as a log (scroll to "Submission Log" at the bottom)

### Section 1: Prohibited Health Claims

Check each ad creative and body copy for the following. Every item must PASS.

| # | Check | PASS/FAIL | Flagged Text (if FAIL) | Fix Applied |
|---|-------|-----------|----------------------|-------------|
| 1.1 | No disease, diagnosis, treatment, or cure language ("reverses aging," "prevents Alzheimer's," "cures fatigue") | | | |
| 1.2 | No before/after transformation claims ("look 10 years younger," "turn back the clock") | | | |
| 1.3 | No absolute outcome guarantees ("you WILL feel different," "guaranteed energy," "proven to," "100% effective") | | | |
| 1.4 | No personal health assertions in second person ("your cells are dying," "your body is broken," "you're aging faster") | | | |
| 1.5 | No references to specific medical conditions (Alzheimer's, diabetes, cancer, heart disease, etc.) | | | |
| 1.6 | No anti-medical framing ("your doctor is wrong," "what your doctor won't tell you") | | | |
| 1.7 | All health claims use structure/function language ("supports," "promotes," "helps maintain") | | | |

**Quick reference — common swaps:**

| If you wrote this | Change to this |
|-------------------|---------------|
| "Reverses aging" | "Supports cellular health as you age" |
| "Cures fatigue" | "Supports consistent daily energy" |
| "Your cells are dying" | "NAD+ levels naturally decline with age" |
| "Fixes your metabolism" | "Supports healthy metabolic function" |
| "Guaranteed results" | "Backed by peer-reviewed research" |
| "You WILL feel more energy" | "Many people notice more consistent energy" |
| "50% of your NAD+" | "A significant decline in NAD+" |
| "DNA repair" | "Cellular maintenance" |
| "Prevents cognitive decline" | "Supports brain health and mental clarity" |

### Section 2: Personal Attributes Policy (Meta-Specific)

Meta's Personal Attributes Policy flags ads that assert knowledge of a user's personal characteristics, including health status. This is the #1 rejection reason for supplement ads.

| # | Check | PASS/FAIL | Flagged Text (if FAIL) | Fix Applied |
|---|-------|-----------|----------------------|-------------|
| 2.1 | No second-person health status assertions ("your NAD+ is depleted," "your energy is declining," "you're exhausted") | | | |
| 2.2 | All health statements use third-person or general framing ("NAD+ naturally declines with age," "cells may produce less energy over time") | | | |
| 2.3 | No implied diagnosis of the viewer ("Are you tired all the time?" "Feeling old?") | | | |
| 2.4 | Questions reframed as possibilities, not diagnoses ("What if feeling depleted isn't inevitable?" not "Are you depleted?") | | | |

### Section 5: Landing Page (PDP) Compliance

Meta reviews your landing page as part of the ad review. If the PDP fails, the ad gets rejected — even if the ad copy itself is clean.

| # | Check | PASS/FAIL | Flagged Text (if FAIL) | Fix Applied |
|---|-------|-----------|----------------------|-------------|
| 5.1 | FDA disclaimer present and visible: *"These statements have not been evaluated by the FDA. This product is not intended to diagnose, treat, cure, or prevent any disease."* | | | |
| 5.2 | No disease claims in product description, benefits section, or FAQ | | | |
| 5.3 | No customer testimonials on PDP claiming to cure or treat a condition | | | |
| 5.4 | Research citations use "supports" not "proves" or "cures" | | | |
| 5.5 | URL slug does not contain condition-specific terms ("anti-aging," "cellular-repair") | | | |
| 5.6 | Product name in Shopify doesn't contain condition-specific language (use "Baseline NMN" not "NMN Anti-Aging Supplement") | | | |
| 5.7 | Meta description and alt tags don't contain health-condition keywords | | | |

## If an Ad Gets Rejected

Follow this protocol — especially on a new ad account:

1. **Do NOT immediately appeal.** Appeals draw human reviewer attention to your entire account. On a new account, this is risky.
2. **Identify the flagged claim.** Check the rejection reason in Meta Ads Manager. Cross-reference with the checklist above.
3. **Duplicate the ad with softer language.** Use the swap table in Section 1. Submit as a new ad, not an edit of the rejected one.
4. **Wait 24-48 hours** after the rejection clears before considering an appeal.
5. **If multiple ads get rejected in the same batch:** Pause ALL ads in that batch. Rewrite the entire batch before resubmitting. Multiple rapid rejections compound account risk.
6. **Log the rejection** in the Rejection Log below.
